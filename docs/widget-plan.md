# 알림 아이콘(위젯) 기획 — 단계 10

> 상태: **기획 확정(2026-11-02)**, 제작 전. 기준: 기획 07 §9의 확정 방향 + 2026-11-02 사용자 결정.
> 이 문서는 개인 내용 없이 쓴다(공개 저장소용). 예시는 가상 회사만.

## 1. 한 줄 요약

job-compass가 볼트에 쓰는 `Areas/취업/_widget/오늘 현황.json`을 **읽기만** 해서, 작업 표시줄 알림 영역의 아이콘과 화면 위에 떠 있는 작은 아이콘으로 "마감 임박·새 후보"를 알려 주고, 누르면 오늘 현황 창을 연다.

## 2. 확정된 것

| 항목 | 결정 |
|---|---|
| 형태 | 스킬과 분리된 **새 앱**(`apps/widget/`). 볼트 폴더 구조에 묶이지 않게 JSON 한 파일만 읽는다 |
| 도구 | **Python + PySide6**(새로 설치 필요, 약 200~300MB. 설치 전에 사용자에게 다시 알린다) |
| 아이콘 ① | **작업 표시줄 오른쪽 아래 알림 영역**(트레이) 아이콘. 항상 있음. 숫자 배지 = 마감 임박 + 새 후보 |
| 아이콘 ② | **화면 위에 늘 떠 있는 작은 아이콘**(항상 위, 테두리 없음, 같은 배지). **마우스로 끌어 옮길 수 있고 위치를 기억**한다. **우클릭 → "아이콘 지우기"**로 숨긴다(트레이 메뉴의 "떠 있는 아이콘 보이기"로 되살림) |
| 창 | **불투명 창**(글씨 가독성 우선). 두 아이콘 어느 쪽을 눌러도 같은 창 |
| 알림(말풍선) | 위젯이 켜져 있으면 **위젯이 맡는다**. 자동 수집(`run_scan.ps1`)은 위젯이 켜져 있을 때 자기 알림을 띄우지 않는다. 위젯이 꺼져 있으면 지금처럼 자동 수집이 알림 |
| 버튼(1차) | **열기만**: 문서를 Obsidian에서(없으면 기본 앱), 공고를 브라우저에서. 윈도우 시작 시 자동 실행 |
| 하지 않는 것 | 볼트 파일 수정·상태 변경·Notion 쓰기·AI 호출·채용 사이트 접속 |
| 나중에 검토 | "지금 수집" 버튼(사용량·시간이 듦), 잠자기에서 깼을 때 오늘 수집이 없으면 한 번 실행(작업 스케줄러 보충의 보완) |

## 3. 화면

```
[알림 영역] 🧭⁶        [화면 위 떠 있는 아이콘] (🧭 6)  ← 끌어서 옮김 · 우클릭: 창 열기 / 아이콘 지우기 / 위치 초기화

창 (아이콘 클릭)
┌─ 취업 현황 · 11/02 09:22 수집 ───────────────────────┐
│ ⚠️ 먼저 볼 것   마감 지난 지원 전 0 · 결과 확인 필요 1       │
│ 📅 마감 임박    A사 · 11/05 (D-3) · 자소서 작성중   [문서]   │
│ 🆕 새 후보      B사 74 🟡 · C사 61 🟡 · D사 34 🔴   [공고]   │
│ ▶ 진행 중      A사  공고✓ 점수✓ 조사✗ 자소서 작성중 면접✗     │
│ 다음 할 일      1. A사 — `/cover-letter 첨삭`              │
│ ───────────────────────────────────────────── │
│ 노션 밀린 반영 0 · 마지막 수집 09:22 성공  [후보함] [오늘 현황] │
└───────────────────────────────────────────────┘
```

- 데이터가 오래되면(오늘 수집이 없음 / `generated_at`이 하루 넘음) 창 위에 "오늘 수집 기록 없음"을 노란색으로.
- 마지막 수집이 실패(코드 ≠ 0)면 빨간 줄로 표시.
- 닫기(×)는 창만 숨긴다. 종료는 트레이 메뉴의 "끝내기".

## 4. 알림 규칙

- JSON이 바뀌면(파일 감시 + 1분마다 확인) 이전 값과 비교해 **늘어난 것만** 알린다: 새 후보 수(`counts.new_candidates_today`), 마감 임박(`counts.urgent`), 마감 지난 지원 전(`counts.overdue`).
- 같은 `generated_at`으로는 한 번만 알린다(마지막으로 알린 값은 위젯 설정 파일에 저장).
- 말풍선 예: `마감 임박 1건 · 새 후보 5건(최고 74점) — 채용 현황을 확인하세요`. 회사 이름은 말풍선에 넣지 않는다(화면 공유 중일 수 있음).
- 알림 넘겨받기: 위젯이 1분마다 `%LOCALAPPDATA%\job-compass-widget\heartbeat`를 갱신 → `run_scan.ps1`은 이 파일이 3분 안에 갱신됐으면 자기 알림을 건너뛴다(볼트에는 쓰지 않는다).

## 5. 데이터 (`오늘 현황.json`)

지금 있는 칸: `generated_at` · `today` · `counts{in_progress, closed, urgent, overdue, wait_result, new_candidates, new_candidates_today, notion_pending}` · `notion` · `last_scan{at, code}` · `urgent[]` · `overdue[]` · `wait_result[]` · `stale[]` · `new_candidates[]`(상위 3: company·direction·score·link) · `in_progress[]` · `next_actions[]` · `warnings[]`.

위젯 1단계에서 `dashboard.py`에 더할 것(볼트 경로는 **볼트 루트 기준 상대 경로**로만):
- `schema: 1` — 위젯이 모르는 판이면 "job-compass를 업데이트하세요"만 보이고 멈추지 않는다.
- `files{candidates, today}` — 후보함·오늘 현황 문서 경로.
- 항목마다 `doc`(공고 wiki 경로, 없으면 null).
- `new_candidates[]`에 `deadline`.

위젯은 이 JSON만 읽는다. 현황표·후보함을 직접 해석하지 않는다(규칙이 두 곳에 생기지 않게).

## 6. 설정 (위젯 쪽, 볼트 밖)

`%APPDATA%\job-compass-widget\settings.json`: 볼트 폴더(처음 실행 때 폴더 고르기), 떠 있는 아이콘 보이기·위치(x, y, 모니터), 마지막으로 알린 `generated_at`·값. 화면 해상도·모니터가 바뀌어 아이콘이 화면 밖이면 오른쪽 아래로 되돌린다.

## 7. 제작 단계

| 단계 | 내용 | 시험 |
|---|---|---|
| W1 | `dashboard.py` JSON 보강(§5) + 위젯 뼈대: 트레이 아이콘·배지·창(읽기 전용)·문서/공고 열기 | JSON 읽기·요약 함수는 자동 시험(화면 없이). 화면은 사용자가 확인 |
| W2 | 떠 있는 아이콘: 끌어 옮기기·위치 기억·우클릭 메뉴(창 열기 / 아이콘 지우기 / 위치 초기화)·화면 밖 보정 | 위치 저장·보정 함수 자동 시험. 끌기·여러 모니터는 사용자 확인 |
| W3 | 알림 규칙(§4)·`run_scan.ps1` 알림 넘겨받기·윈도우 시작 시 자동 실행(시작 프로그램 바로가기, 미리보기 후 확인) | 비교·중복 방지 함수 자동 시험. 토스트는 사용자 확인 |
| W4(나중) | "지금 수집" 버튼, 깨어날 때 오늘 수집 확인 | 별도 결정 |

- 설치: `pip install --user PySide6`(W1 시작 전에 사용자에게 알리고 확인). 실행은 `pythonw`로 창 없이.
- 위젯은 공개 저장소에 들어가도 되게 개인 내용·볼트 경로를 코드에 넣지 않는다.

## 8. 미시험(만들기 전)

PySide6 트레이 배지 표시, 항상 위 창이 전체 화면 앱 위에 뜨는지, `obsidian://` 주소로 문서가 열리는지, 잠자기 후 파일 감시가 계속 되는지, 여러 모니터·화면 배율에서 위치 기억.
