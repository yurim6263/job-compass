# 이름 규칙 (회사 · 직무 · 파일명)

모든 스킬이 같은 규칙을 쓴다. 이 규칙으로 정한 `<회사>`·`<직무>`가 raw · wiki · output · 현황표 · 자소서 · 면접 파일 이름을 서로 이어 주는 접착제다. 예시는 가상이다.

## 회사·직무
| | 규칙 | 예 |
|---|---|---|
| 회사 | 공고에 적힌 한국어 회사명만. `㈜` `(주)`와 괄호 속 영문 표기는 뺀다 | `㈜가나다(Ganada)` → `가나다` |
| 직무 | 공고 제목에서 머리 꼬리표 `[…]`를 빼고, 괄호는 기호만 빼서 띄어 쓴다 | `[투자유치] Node.js개발자(신입)` → `Node.js개발자 신입` |
| 공통 | `\ / : * ? " < > \| # ^ [ ]` 는 뺀다. 끝의 점·공백도 뺀다. `CON` `PRN` `AUX` `NUL` `COM1`~`9` `LPT1`~`9` 만으로 된 이름은 쓰지 않는다 | |

## 파일 이름
| 종류 | 규칙 | 예 |
|---|---|---|
| raw 공고 | `<오늘>_<회사>-<직무>` — 공백은 `-`, `.`은 뺀다 | `2026-10-31_A사-설비-AI-엔지니어-신입` |
| wiki 공고 | `채용공고_<회사> <직무>` — 공백·`.` 유지 | `채용공고_A사 설비 AI 엔지니어 신입` |
| output | `<오늘> <회사> <직무> 지원 준비` (같은 날 두 번이면 끝에 ` 2`) | `2026-10-31 A사 설비 AI 엔지니어 신입 지원 준비` |
| 임시·원본 파일 이름 | 공고 ID의 `:`를 `-`로 (Windows는 파일명에 `:`가 있으면 숨은 스트림이 된다) | `jobkorea-1001` |
| 태그 | 공백·점이 없는 낱말 | `Nodejs` · `서버개발` |

- 모르는 사이트의 공고 ID는 `url-<호스트>`로 시작한다.
- 같은 회사·같은 직무의 재공고는 wiki 파일명 끝에 ` <수집 연월>`(예: ` 2027-03`)을 붙여 구분한다.
- 뒤 스킬(`/company-research`·`/cover-letter`·`/mock-interview`)이 쓰는 `<회사>_<직무>`는 위 `<회사>`와 `<직무>`를 `_`로 이은 것이다.
