# 교육 이수 정리 형식 (`/exp-organize`의 `교육` 모드가 쓰고 `course_tools.py`가 검사한다)

경험 카드는 **내가 한 일**(결과물)을, 교육 이수 정리는 **내가 배운 것**(과정·기술·수준)을 적는다. 둘을 섞지 않는다.
교육 과정에서 내가 만든 과제·프로젝트는 지금처럼 `origin: 교육과제` **경험 카드**로 만들고, 교육 이수 정리에서는 그 카드 id를 연결만 한다.
예시는 모두 가상이다.

## 파일 `wiki/교육이수_<과정 이름>.md` (과정 하나 = 파일 하나)

```
---
tags: [교육이수]
sources:
  - "[[Projects/SecondBrain/raw/내경험/<폴더>/커리큘럼.pdf|커리큘럼]]"
updated: YYYY-MM-DD
origin: 교육과정
---

# <과정 이름>

### edu-YYYYMMDD-NN <과정 이름>
- institution: 가상교육원
- period: 2025-03 ~ 2025-08
- hours: 600시간
- completion: 수료
- job_link_tags: [데이터파이프라인, ML/DL, LLM응용]
- skills:
  - 데이터 전처리(pandas) | 실습 | [[Projects/SecondBrain/raw/내경험/<폴더>/실습1.ipynb|실습1]] — 2주차
  - AWS EC2 배포 | 수강 | [[Projects/SecondBrain/raw/내경험/<폴더>/커리큘럼.pdf|커리큘럼]] — 9주차
  - FastAPI 백엔드 | 과제 | exp-20261031-05
- projects: [exp-20261031-05]
- evidence:
  - [[Projects/SecondBrain/raw/내경험/<폴더>/커리큘럼.pdf|커리큘럼]] — 과정 개요·기간
- fact_status: 자료확인
```

| 필드 | 필수 | 값 |
|---|---|---|
| `institution` · `period` | Y | 자료에 적힌 그대로. 모르면 `[확인 필요]` |
| `hours` | N | 자료에 있을 때만 |
| `completion` | Y | `수료` · `수강중` · `중도` · `[확인 필요]`. 수료증이 없으면 `본인진술`로만 `수료` |
| `job_link_tags` | N | 카드와 같은 목록(`제조AI` `설비데이터` `예지보전` `CBM` `시계열예측` `ML/DL` `LLM응용` `데이터파이프라인` `프론트/웹`)에서만 |
| `skills` | Y(1개 이상) | 줄마다 `기술 \| 수준 \| 근거`. 수준은 **`수강`**(강의만 — 커리큘럼·강의 자료가 근거) · **`실습`**(따라 해 본 내 파일이 있음) · **`과제`**(내가 만든 결과물 — 근거 칸에 교육과제 **카드 id**). 근거가 없는 기술은 쓰지 않는다 |
| `projects` | N | 이 과정에서 만든 교육과제 카드 id 목록 |
| `evidence` | Y | 과정 자체의 근거(커리큘럼·수료 사실 노트·안내문). 줄마다 `[[raw 링크\|이름]] — 위치` |
| `fact_status` | Y | `자료확인` · `본인진술` · `미확인` (카드와 같은 뜻) |

## 쓰는 규칙
1. **배운 것은 배운 것으로만.** "AWS로 서비스를 운영했다"처럼 실무·성과로 바꿔 쓰지 않는다. 수준을 올려 적지 않는다(커리큘럼에만 있으면 `수강`).
2. 받은 강의 자료(`받은교재`)는 카드는 못 만들지만 **`수강` 수준의 근거**로는 쓴다.
3. 수료증은 볼트 규칙대로 사실 노트(이름·번호 없이 과정명·기간·수료 여부)만 근거로 쓴다.
4. 점수(`/job-posting`)에서는 교육 이수 id(`edu-…`)를 인용해도 **최대 `부분`**이다(`score_calc.py`가 `증명`을 `부분`으로 내린다). 사용 기술 낱말이 교육 이수에만 있으면 절반만 인정한다.
5. 자소서에서는 "교육 과정에서 ○○을 실습했다"까지만 쓸 수 있고, 성과·수치는 교육과제 카드에 있을 때만.
6. 검사: `python -I -X utf8 .claude/skills/_공용/scripts/course_tools.py check Projects/SecondBrain/wiki/교육이수_<과정>.md`
