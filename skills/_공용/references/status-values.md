# 현황표 값 목록 (스크립트 `jc_job.py`와 같아야 한다)

현황표는 `Areas/취업/지원 현황.md`, 13열: 기업명 · 직무 · 진행상태 · 유형 · 서류마감 · 공고 · 공고 ID · 채널 · 상태일 · 메모 · 적합도 · 지역 · 최종 단계.

| 열 | 값 |
|---|---|
| 진행상태 | 할 일: `Not started` · `일정 + 자소서 항목 정리` / 진행: `인적사항 입력완료` · `자소서 작성중` · `자소서 작성 완료` · `지원완료` / 완료: `서류합` · `역량검사` · `인적성` · `1차면접` · `2차면접` · `최종면접` · `최종합` · `불합` · `지원취소` |
| 직무 | `제조AI` · `CBM시스템개발자` · `LLM응용` · `데이터` · `기타` 중 낱말 하나 (애매하면 사용자에게 묻는다) |
| 유형 | `신입` · `인턴` · `채용연계` 중 하나, 안 맞으면 비움 |
| 서류마감 | `YYYY-MM-DD`. 공고에 없으면 비움 |
| 적합도 | `74 🟡` (게이트 🚫가 있으면 뒤에 `🚫석사 이상 필수`처럼) · 점수를 못 냈으면 `미산출` |
| 지역 | `서울` · `경기` · `대구` · `부산` · `울산` · `포항` · `그 밖` · `원격` · `미기재` |
| 최종 단계 | 지금까지 도달한 가장 높은 단계(위 진행상태 값). 불합·지원취소가 돼도 남는다 |

- 전형 순서는 회사마다 다르다(역량검사·인적성이 앞뒤). 순서를 강제하지 않고 건너뛰기를 허용한다. 상태는 뒤로 가지 않는다.
- 입사·입사포기·무응답·지원안함은 진행상태 값이 아니다. 상태는 두고 메모에 `YYYY-MM-DD 입사포기`처럼 적는다.
- 행 **추가**는 `/job-posting`, 상태·메모·최종 단계 수정은 `/job-flow`(없는 볼트에서만 `/job-posting`이 임시로 `status_table.py set-status`를 쓴다).
