# AI 역량검사 연습 (연습용 문항 은행 — 실제 검사 문항이 아니다)

시작할 때 한 줄로 알린다: "실제 검사의 문항·채점 기준은 공개되지 않아 알 수 없습니다. 이 연습은 형식 익히기와 일관성 연습이며 실제 점수를 예측할 수 없습니다." **정답 성향을 안내하지 않고 솔직·일관만 다룬다.** 적성검사(수리·언어·도형 풀이)는 범위 밖이다.
문항은 이 저장소에서 새로 쓴 연습용이다. 한 번에 하나씩 제시하고 5점 척도(1 전혀 아니다 ~ 5 매우 그렇다)로 답을 받는다.

## ② 성향 일관성 — 24문항 (A~F 여섯 쌍 = 교차 쌍 12문항 + 단독 12문항)
같은 성향을 다른 문장·반대 문항으로 묻는 쌍이 6개다. 쌍은 **서로 떨어뜨려** 제시한다(문항 번호를 섞는다).

| 쌍 | 문항 (정) | 문항 (역·다른 표현) |
|---|---|---|
| A 계획성 | A1. 일을 시작하기 전에 순서를 정해 둔다. | A2. 일단 시작하고 나서 순서를 생각하는 편이다. (역) |
| B 팀 의견 | B1. 의견이 다르면 상대의 이유를 먼저 묻는다. | B2. 내 생각이 맞다고 느끼면 다른 의견은 듣기 어렵다. (역) |
| C 압박 | C1. 마감이 가까워져도 평소 속도를 유지한다. | C2. 마감이 다가오면 실수가 눈에 띄게 늘어난다. (역) |
| D 새로움 | D1. 처음 쓰는 도구도 직접 만져 보며 익히는 편이다. | D2. 익숙하지 않은 방법은 가급적 피한다. (역) |
| E 책임 | E1. 내 몫의 결과가 부족하면 이유를 먼저 따져 본다. | E2. 결과가 나빠도 상황 탓이 더 크다고 생각하는 편이다. (역) |
| F 꼼꼼함 | F1. 제출 전에 숫자와 이름을 한 번 더 확인한다. | F2. 큰 흐름만 맞으면 세부는 넘어가도 된다고 생각한다. (역) |

단독 문항 12개(일관성 쌍에 넣지 않는다, 분산 제시용):
1. 모르는 것을 알게 되면 기록해 둔다. 2. 처음 만난 사람과도 대화를 시작하는 편이다. 3. 정해진 방식이 있어도 더 나은 방법을 찾아본다. 4. 피드백을 들으면 그날 안에 고칠 것을 적는다. 5. 일정이 바뀌어도 우선순위를 다시 정하면 당황하지 않는다. 6. 팀에서 맡은 일이 아니어도 막힌 동료를 돕는다. 7. 한 가지 일에 오래 집중하는 것이 어렵지 않다. 8. 실수를 발견하면 곧바로 알린다. 9. 결과를 숫자로 확인하는 것을 좋아한다. 10. 규칙의 이유를 이해해야 따르기 쉽다. 11. 낯선 환경에서도 금방 적응하는 편이다. 12. 일을 마친 뒤 무엇이 잘됐는지 돌아본다.

**판정**: 정 문항과 역 문항(역은 점수를 뒤집어 6−x로 읽는다)의 차이가 **2점 이상** 나는 쌍의 개수를 센다(예: A1=5, A2=4 → 뒤집으면 2 → 차이 3). 차이 2 이상인 쌍이 2개 이상이면 "일관성 흔들림 — 어떤 상황을 떠올리며 답했나?"를 묻는다. 좋고 나쁜 성향을 평가하지 않는다. 개수만 보여 준다(`일관성 어긋난 쌍 n/6`).

## ③ 상황판단(SJT) — 4~6개
공고 직무와 카드에서 상황을 만들어 **가상 상황**이라고 표시한다. 형식: 상황 3문장 → 선택지 3~4개 → **선택 + 이유**. 이유가 선택·이전 답과 일관되는지만 본다(정답을 강요하지 않음). 상황 소재 예(제조AI): 설비 센서에서 이상값이 한꺼번에 나옴 / 일정과 검증 중 하나를 줄여야 함 / 팀원이 내 전처리 규칙에 반대함 / 현장 담당자가 모델 결과를 믿지 못함.

## ④ 응답 형식 연습
"60초 이내(약 200자)" 같은 제한을 두고 한 문항에 답하게 한다 → 두괄식·분량 코칭(체크리스트 2·8번). 시간은 측정하지 못하고 글자수로 환산한다.

## ① 게임형 과제 대비 · ⑤ 환경 점검
- 게임형(반응속도·집중력·기억): **설명과 준비 요령만** 안내한다. 글로는 게임을 할 수 없다. 해당 기업의 연습 채널을 안내하기 전에 **검색으로 지금도 운영되는지 확인**한다.
- 환경 점검 체크리스트(사용자가 체크): 카메라 · 조명 · 네트워크 · 조용한 공간 · 대기 화면 · 전원 연결 · 브라우저 권한.

## 구직자 권리 한 줄
채용에 AI 자동 판단이 쓰이는 경우의 설명 요구·거부에 관한 법 조항은 시행 상태를 단정하지 않고 **필요하면 검색으로 확인해 출처·기준일과 함께** 안내한다.
