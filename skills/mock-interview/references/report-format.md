# 리포트 · 기록 형식

세션 리포트 `Areas/취업/면접/<회사>_<직무>/YYYY-MM-DD_<모드>_<강도>.md` (경로는 `interview_tools.py next-path`). 사실의 근거는 wiki 카드이고 리포트에는 **카드 id와 답변 인용**만 둔다. 제3자 실명은 익명화.

```
# <회사> <직무> — <모드> · <강도> · YYYY-MM-DD

> 피드백 방식: 즉시|마지막 · 글로 하는 연습(목소리·표정·실제 시간은 측정하지 못함) · 중단이면 `중단` 표시

## 통과율            ← interview_tools.py calc 출력 그대로(산정 n/m)
## 사실 일치         ← 7번. 서류와 다르게 말한 곳(자소서 문장 vs 답변 vs 카드 id)과 사용자가 정한 쪽
## 강점 3            ← 답변 인용
## 개선점 3          ← 인용 + 대안(방향만, 전문 모범답안 금지)
## 질문별 기록
### Q1 [지원동기] <질문>
- 내 답변(요약·핵심 인용)
- 체크리스트: 예 n / 해당 m — 아니오 항목: …(인용)
- revision(선택): 내가 한 말과 카드 사실로만 다시 쓴 것, 없는 수치는 [수치 확인 필요]
- 꼬리질문: …
## 방어 맵 활용     ← 활용률, 갱신한 방어 상태(id → 상태)
## 다음 연습 질문 3
## 면접 팁
```
- 방어 맵 활용률 = 답변에서 실제로 쓴 미끼 수 ÷ 방어 맵 항목 수(방어 맵이 있을 때).
- 기록 요약(`Areas/취업/면접/기록 요약.md`)은 `interview_tools.py log-summary`가 쌓는다. 실전 질문 은행은 `bank-add`.
- 같은 날 같은 모드를 반복하면 `_2`를 붙이고 덮어쓰지 않는다. `wiki/`·`raw/`는 건드리지 않는다.
