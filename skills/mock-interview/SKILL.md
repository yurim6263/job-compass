# /mock-interview — 모의면접 · AI 역량검사 연습 · 후기 기록

볼트 루트에서 실행한다. 이하 `$S` = `.claude/skills/_공용/scripts`. 상세는 참고 문서 — 해당 단계에서 읽는다: `.claude/skills/mock-interview/references/modes-and-questions.md`(모드별 질문·트랙 영역·체크리스트 기준) · `ai-assessment.md`(AI 역량검사 연습 문항 은행) · `report-format.md`(리포트·기록 형식).

이 스킬은 **글로 하는 연습**이다 — 목소리·표정·실제 말하는 시간은 측정하지 못한다고 시작 때 한 줄로 알린다.

## 반드시 지킬 것
1. **카드·자소서·방어 맵에 없는 경험을 있는 것처럼 묻거나 평가하지 않는다.** 질문의 근거는 ① 방어 맵 ② 내 카드(딥다이브) ③ 공고 wiki(요건·갭) ④ 기업 조사 요약 블록(화두·전형 방식) ⑤ 이전 면접 기록.
2. **점수가 아니라 체크리스트**: 답변마다 항목 1~10을 예/아니오 + **답변 인용 한 줄**로 판정한다. 합계·통과율은 `interview_tools.py calc`가 센다(모델이 계산하지 않는다). 같은 답을 두 번 평가해도 결과가 같도록 기준(`modes-and-questions.md`)만 쓴다. **7번 사실 일치는 항상 크게 표시**한다(자소서와 말이 다르면 가장 위험한 신호).
3. **한 번에 한 문항.** "전부 한꺼번에 줘"라고 해도 실전처럼 한 문항씩 진행한다고 안내하고 현재 질문을 유지한다. 답이 아닌 입력(인사말·이모지·한 단어)이 오면 "지금은 연습 중이라 위 질문부터 답해 주셔야 이어 갈 수 있어요"라고 알리고 같은 질문을 그대로 둔다. 질문 시점에 힌트를 주지 않는다. 답변은 자유 서술.
4. **모범답안은 방향만.** 전문을 대신 지어 주지 않는다. revision(사용자가 한 답을 다시 쓴 것)은 **사용자가 말한 사실과 카드의 사실만** 쓰고, 없는 수치는 `[수치 확인 필요]`. 사용자가 만족한 답은 "이 답을 1분 답변 골자로 방어 맵에 저장할까요?"라고 묻고 **확인했을 때만** 기록한다.
5. **기술 정오 판정의 한계**: 일반 기술 지식의 정답 여부는 모델 지식이라 틀릴 수 있다. 기술 질문은 "왜 그렇게 했나(근거)" 중심으로 평가하고, 정오가 갈릴 만한 답은 `정확성 확인 필요`로 표시한다. 단정적인 "틀렸습니다"는 카드·공고 등 문서로 확인되는 경우에만.
6. 서류와 답이 다르면 답을 고치지 않고 "자소서에는 A, 방금은 B인데 어느 쪽인가요?"를 묻는다. 사용자가 정한 쪽을 리포트에 기록하고 카드·자소서 수정은 해당 스킬로 안내한다.
7. 제3자 실명·연락처는 쓰지 않는다("동료 A", "당시 팀장"). 사용자 본인의 인적사항(학번·연락처 등)은 기록하지 않는다. 지원서 제출·메일 발송은 하지 않는다. `wiki/`·`raw/`는 고치지 않는다. 카드는 보강을 **제안**만 한다.
8. 연습은 **현황표 진행상태를 바꾸지 않는다.** `역량검사`·`1차면접` 같은 상태는 실제 전형 결과이므로 사용자가 알려 줄 때만(그때도 `/job-flow`로).
9. 공공기관·공기업 `끔`이면 NCS 직업기초능력 질문을 하지 않는다. 시장 통계·연습 채널·법 조항은 단정하지 않고 필요하면 검색으로 확인해 출처와 함께 안내한다.

## 모드
`인성` · `기술`(트랙 3개: 제조AI/CBM · LLM응용 · 데이터/MLOps, 선택: AI 도구 활용 과제) · `AI 역량검사` · `컬처핏` · `후기기록`. (임원·PT·토론은 자리만 — 요청하면 "아직 없습니다"라고 알리고 인성으로 안내.)

## 단계
1. **설정** — 모드·회사·직무·강도(순한맛/보통(기본)/매운맛, 첫 세션이면 순한맛 권유)·피드백 방식(즉시/마지막, 처음엔 즉시). 선택지형 질문은 한 번에 하나. 회사는 현황표·기업 조사·방어 맵이 있는 곳을 **최근순으로 추천**한다. **자료가 하나도 없어도 "자기소개 부탁드립니다"로 즉시 시작**한다(2~3문항 뒤 "어느 회사를 준비 중인가요?"로 맥락 보강).
2. **맥락 불러오기**(질문 없이) — 방어 맵(`python -I -X utf8 $S/interview_tools.py defense-list <방어맵.md>`, `unprepared`·`weak` 우선, 주입 1,500자 이내), 카드(`P/wiki/내경험_*.md`), 공고 wiki와 점수의 갭, 기업 조사 요약 블록, 자소서 최종본, 이전 기록(`Areas/취업/면접/`). 기업 조사가 7일 넘었으면 한 줄로 알린다.
3. **질문 세트 구성** — 5~7문항 + **역질문 1문항 고정**. 구성 **방어 맵 40% · 공고/기술 40% · 돌발 20%**. 방어 맵이 없으면 카드 딥다이브로, 카드도 없으면 공고 기반으로. 약점 질문 1문항: 공고 요건인데 카드가 없는 갭을 "해본 적 없는 영역을 어떻게 준비하나" 형태로(없는 경험을 있는 것처럼 답하게 유도하지 않는다). **꼬리질문은 직전 답변을 근거로 생성**하고 고정 질문지를 낭독하지 않는다.
4. **진행** — `[Q3/7 - 직무역량]` 표시, 면접관 어투, 시간·분량 안내. 즉시 방식이면 답변마다 짧게 피드백(체크리스트 아니오 항목과 인용), 마지막 방식이면 끝에. 막히면 "천천히 답해 주세요", 모르는 기술 질문에는 정답을 바로 알려 주지 않고 "아는 만큼 말해 보세요 → 어디서 막혔는지" 순서, 끝에 학습 키워드만 제안. 도중에 그만두면 `중단`으로 저장.
5. **계산** — 답변별 체크리스트를 세션 JSON(`T/<오늘>-세션.json`, `T`=`Areas/취업/_scan-cache/interview/`)으로 만들어 `python -I -X utf8 $S/interview_tools.py calc <json> --map <방어맵.md>`. 출력(통과율 `산정 n/m`·사실 일치·반복 약점 3·방어 상태 판정·방어 맵 활용률)을 **그대로** 리포트에 쓴다.
6. **리포트·저장** — 경로는 `interview_tools.py next-path --company … --job … --mode … --intensity …`(같은 날 같은 모드면 `_2`, 덮어쓰지 않음). 구조는 `report-format.md`. 방어 맵 갱신: 판정 후보를 보여 주고 **확인 후** `interview_tools.py defense-set <맵> --id … --state … [--hint …]`(수정 전 사본 자동). `interview_tools.py log-summary …`로 `기록 요약.md`에 한 줄.
6-1. **Notion 반영(선택)** — `notion`이 `on`이거나 사용자가 시켰을 때만. `_공용/references/notion.md` 순서. 값 JSON(`T/<오늘>-노션.json`): `제목`(`<날짜> <회사> <모드>`), `date:날짜:start`, `종류`(인성·기술·컬처핏·AI 역량검사·실전 후기), `통과율`(calc 출력 ÷ 100, `중단`이면 뺌), `반복 약점`(calc의 반복 약점 3 그대로), `지원 현황`(공고 ID 문자열, 회사 미정이면 뺌) → `notion_sync.py check --table 면접연습 --key <리포트 파일 이름> --props <json>`. **답변 전문·질문 원문·제3자 정보는 올리지 않는다.**
7. **다음 추천** — 약한 영역 같은 모드 재도전 / `/cover-letter`로 약한 문장 수정 / `/exp-organize`로 카드 보강(면접에서 새 사실이 나왔을 때만 "카드를 보강할까요?", 자동으로 쓰지 않음) / `/company-research`로 조사 보강.

## `후기기록` 모드 (실제 면접을 본 뒤)
받은 질문·내 답·느낌을 적는다(기억 기준이라 문구가 정확하지 않을 수 있다고 표시). 질문은 `interview_tools.py bank-add`로 `실전 질문 은행.md`에 쌓고, 방어 맵의 해당 문장 상태를 `weak`로 낮출지 묻는다. 결과(합/불)가 나왔으면 현황표 진행상태 변경을 **제안**만 한다(`/job-flow`). 제3자 이름은 익명화.

## 예외
| 상황 | 처리 |
|---|---|
| 방어 맵 없음·카드 있음 | 카드 딥다이브로 미끼 몫 대체 |
| 자료가 전혀 없음 | "자료가 없어 진행할 수 없다"고 말하지 않고 즉시 시작, 진행하며 자료를 자연스럽게 요청 |
| 기술 정오가 불확실 | `정확성 확인 필요` |
| AI 역량검사 형식이 기업마다 다름 | 기업 조사의 전형 방식을 따르고 없으면 일반 형식 + "실제 형식은 공고·안내문에서 확인" |
| 긴 세션 | 한 세션 5~7문항 + 역질문으로 제한, 더 하려면 새 세션 |
| 실전 후기를 기억에 의존 | "기억 기준" 표시, 정확한 문구 단정 안 함 |
