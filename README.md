# job-compass

신입 취업 준비를 위한 **Claude Code 스킬 묶음**입니다. 내 경험을 카드로 정리하고, 채용공고를 내 경험에 맞춰 점수화하고, 마감일과 지원 현황을 관리하고, 자기소개서·면접 준비까지 이어 갑니다. 개인용 도구이고, 모든 자료는 **내 컴퓨터의 Obsidian 볼트에 저장**됩니다.

> **상태: 개발 중입니다.** 스킬 8개가 만들어져 있고 가상 자료(가짜 볼트)에서 시험 중입니다. 실제 자료로는 아직 확인하지 않았습니다. 공개 저장소로 쓸 수 있는 상태가 아닙니다(공개 전 점검 전).

## 스킬 (8개)

| 스킬 | 하는 일 |
|---|---|
| `/exp-intake` | 경험 원자료(노션 내보내기·깃허브·문서·pdf·hwp 등)를 볼트로 가져오기 |
| `/exp-organize` | 가져온 자료를 근거가 달린 **경험 카드**로 정리 |
| `/job-posting` | 채용공고 1건 분석 → 요건별 판정·점수·현황표·마감 캘린더 |
| `/job-scan` | 검색 조건으로 공고 후보 모으기 (수동 실행, 예약 실행 스크립트 포함) |
| `/company-research` | 기업 조사, 키워드 체크리스트, 지원 판단 |
| `/cover-letter` | 자소서 항목 정리, 카드 자동 추천, 첨삭, 면접 질문 연결 |
| `/mock-interview` | 모의면접, AI 역량검사 연습, 후기 기록 |
| `/job-flow` | 오늘 현황, 상태 갱신, 통계, 다음 행동 안내 |

## 원칙

- **카드에 없는 사실은 쓰지 않습니다.** 수치·역할·기간을 지어내지 않고 근거가 없는 문장은 표시합니다.
- **점수·날짜·정렬·글자수는 스크립트가 계산합니다.** 모델의 느낌으로 숫자를 정하지 않습니다(`skills/_공용/scripts/`).
- **제출·발송은 하지 않습니다.** 지원서 제출과 메일 발송은 어떤 스킬도 하지 않습니다.
- **로컬 우선.** 정본은 내 볼트의 파일이고 Notion·엑셀·워드는 선택적 사본입니다. Notion 반영은 설정에서 켰을 때만, 미리보기를 보여 주고 확인을 받은 뒤 씁니다(볼트 → Notion 한 방향, 삭제 없음). Notion 페이지 하나 안에 표 6개(지원 현황·수집 공고·회사 조사·자소서·면접 연습·경험 정리)를 두며, 규칙은 `skills/_공용/references/notion.md`에 있습니다. 예약 실행은 Notion에 쓰지 않습니다.

## 저장소 구성

```
skills/      스킬 8개와 공용 부품(_공용: 스크립트·참고 문서)
fixtures/    시험용 가짜 볼트 · 가상 공고 · 시험 기대표 (가상의 회사·프로젝트·공고만 있음)
tools/       배포 스크립트, 가상 시험 자료 생성기
tests/       스크립트 자동 시험(표준 라이브러리 unittest만 사용, 모델은 부르지 않음)
```

## 자동 시험

스크립트가 하는 계산·파일 처리(점수, 현황표, 캘린더, 카드 추천, 글자수 등)는 가짜 볼트 사본에서 자동으로 시험합니다. 저장소 루트에서:

```
python -I -X utf8 -m unittest discover -s tests -v
```

모델(Claude)이 하는 판정·글쓰기는 이 시험에 포함되지 않습니다.

## 알아 둘 점

- 개인 용도의 도구입니다. 채용 결과를 보장하지 않고, AI 작성 탐지를 통과한다고 보장하지 않으며, **사실 확인과 제출은 사용자의 책임**입니다.
- 채용 사이트의 목록을 읽는 기능을 쓸 때는 각 사이트의 이용약관과 robots 정책을 사용자가 확인해야 합니다.
- 한글(.hwp·.hwpx) 문서는 PC에 한글(Hancom) 프로그램이 설치돼 있으면, 사용자 동의를 받은 뒤 한글의 자동 조작 기능(COM)으로 PDF로 바꿔 읽습니다(원본은 그대로). 한글이 없으면 PDF로 저장해 달라고 요청합니다. 선택 도구 `pyhwp`(AGPL, 별도 설치)가 있으면 그것도 씁니다. 시험의 실제 변환 부분은 한글이 없는 PC에서 건너뜁니다.
- 예약 실행(작업 스케줄러)은 스크립트만 있고 기본은 미리보기입니다. 실제 등록·무인 실행은 사용자가 정해야 합니다. Claude Code 계정을 설정 폴더로 나눠 쓴다면(`CLAUDE_CONFIG_DIR`) 등록할 때 `-ConfigDir <설정 폴더>`를 줘야 그 계정으로 실행됩니다 — 작업 스케줄러는 터미널의 환경 변수를 물려받지 않습니다.
